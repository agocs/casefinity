About

Casefinity is a parametric model generator for the "Gridfinity for Hardcases" system — a set of 3D-printable inserts that turn a hard case into an organized tool and parts storage system.

Models are defined as code against the replicad API (OpenCascade B-rep kernel compiled to WASM) and built in a web worker. The site is fully static — no backend. Your models never leave your computer. I collect no information except for Cloudflare telemetry.

The original Gridfinity or Hardcases designs were created by the Unemployed Architecht. You should subscribe to his Patreon
