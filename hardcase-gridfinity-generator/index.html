About

Hardcase Gridfinity Generator is a parametric model generator for the Hardcase Gridfinity system — a set of 3D-printable inserts that turn a hard case into an organized tool and parts storage system.

Models are defined as code against the replicad API (OpenCascade B-rep kernel compiled to WASM) and built in a web worker. The site is fully static — no backend.

The original Hardcase Gridfinity designs were created by the Hardcase Gridfinity author. License for publishing a public generator is unresolved.
